# CLI Reference

All Phileas commands with usage, options, and examples.

## Global options

```
phileas --version    Show version number
phileas --help       Show help for any command
```

---

## phileas init

Interactive setup wizard. Picks usage mode (Claude Code / standalone / both), creates the config file, optionally configures an LLM provider, wires the MCP entry and recall skill into Claude Code, and downloads the embedding and reranker models.

```bash
phileas init
```

API keys are read from environment variables — never written to disk. Re-running `phileas init` overwrites the existing config file.

---

## phileas remember

Store a memory.

```
phileas remember TEXT [--type TYPE] [--importance N]
```

| Option | Default | Description |
|--------|---------|-------------|
| `--type` | `knowledge` | Memory type: `profile`, `event`, `knowledge`, `behavior`, `reflection` |
| `--importance` | LLM-scored | Score 1 (trivial) – 10 (critical). Auto-scored by the LLM when omitted. |

```bash
phileas remember "I prefer Python for backend work"
phileas remember "My name is Alex Chen" --type profile --importance 9
phileas remember "Started at Acme Corp in March 2026" --type event
phileas remember "I like detailed code reviews" --type behavior
```

**Memory types:**
- `profile` — Who the user is: name, identity, core traits
- `event` — Things that happened: dates, milestones, life events
- `knowledge` — Facts and expertise: skills, preferences, opinions
- `behavior` — Patterns and habits: workflows, communication style
- `reflection` — Higher-level insights (typically generated by `reflect`)

## phileas recall

Search memories by natural language query.

```
phileas recall QUERY [--top-k N] [--type TYPE]
```

| Option | Default | Description |
|--------|---------|-------------|
| `--top-k` | config | Maximum number of results |
| `--type` | *all types* | Filter by memory type |

```bash
phileas recall "what programming languages do I use"
phileas recall "work history" --top-k 5
phileas recall "who am I" --type profile
```

The pipeline gathers candidates from keyword (SQLite FTS), vector (ChromaDB), and graph (KuzuDB) sources, then runs a cross-encoder rerank and MMR for diversity. Final scores blend relevance, importance, recency, and access frequency.

---

## phileas forget

Archive a memory so it is no longer returned in searches.

```
phileas forget MEMORY_ID [--reason TEXT]
```

```bash
phileas forget a1b2c3d4
phileas forget a1b2c3d4 --reason "no longer accurate"
```

Archived memories are kept in the database but excluded from search results.

---

## phileas update

Update a memory's summary in place.

```
phileas update MEMORY_ID SUMMARY
```

```bash
phileas update a1b2c3d4 "I'm a senior backend engineer who loves distributed systems"
```

The old version is archived as a snapshot and linked via a `SUPERSEDES` edge in the knowledge graph, preserving the correction trail. Original creation date and identity are preserved.

## phileas list

Browse stored memories.

```
phileas list [--type TYPE] [--limit N]
```

```bash
phileas list
phileas list --type profile
phileas list --limit 50
```

## phileas show

Show full detail of a single memory.

```
phileas show MEMORY_ID
```

Displays ID, summary, type, importance, status, access count, daily reference, and timestamps.

---

## phileas reflect

Synthesize higher-level reflection memories from a day's activity.

```
phileas reflect [--date YYYY-MM-DD]
```

Defaults to today. Reads the day's memories, asks the LLM to surface themes/patterns/decisions, and writes them back as `reflection` memories.

## phileas infer-graph

Run graph inference to discover relationships and patterns across existing memories.

```bash
phileas infer-graph
```

---

## phileas retry-events

Retry failed ingest events (re-run extraction). Requires the daemon.

```
phileas retry-events [EVENT_ID ...]
```

With no args, requeues every event in `failed` state. Pass one or more event-id prefixes to retry specific events.

---

## phileas export

Export all active memories as JSON.

```
phileas export [--format json] [-o PATH]
```

```bash
phileas export                       # stdout
phileas export -o ~/backup/memories.json
```

---

## phileas serve

Start the Phileas MCP server for AI client integration.

```bash
phileas serve
```

Exposes memory tools (`memorize`, `recall`, `forget`, `update`, `relate`, `about`, `timeline`, `status`, …) over the Model Context Protocol. See [MCP Integration](mcp-integration.md) for client configuration.

---

## phileas start / stop

Run the Phileas daemon in the background so the CLI doesn't pay model-load cost per invocation.

```bash
phileas start              # background
phileas start --foreground # for systemd / supervised
phileas stop
```

## phileas status

Show system health and memory statistics as a Rich table (total / active / archived counts, embedding count, graph nodes and edges).

```bash
phileas status
```

## phileas stats

Observability for Phileas. Subcommands cover LLM usage, memory lifecycle, graph health, ingest, recall, consolidation, and daemon health.

```
phileas stats <subcommand>
```

| Subcommand | What it shows |
|---|---|
| `overview` | Everything at a glance |
| `llm` | LLM tokens, cost, by-op, failures |
| `memory` | Memorize rate by type |
| `graph` | Node/edge counts + entity-type breakdown |
| `ingest` | Ingest rate, dedup rate, entity coverage by type |
| `recall` | Top-1 hit rate, empty rate, latency, hot-hit rate |
| `consolidation` | Reflection runs — count, cost, last run |
| `daemon` | Uptime markers, errors, lock contention |
| `watch` | Re-render a stats view every N seconds |

---

## phileas usage

Alias for `phileas stats llm` — tokens, cost, requests by operation.

```
phileas usage [--since 24h|7d|30d|all]
```

---

## phileas migrate-recall

Install the Phileas recall skill at `~/.claude/skills/phileas/SKILL.md` and reconcile the hook entry in `~/.claude/settings.json` against `recall.mode` from the config. Pass `--force` to overwrite a customized SKILL.md.

```bash
phileas migrate-recall
phileas migrate-recall --force
```

## Deprecated commands

These commands remain in `--help` for backward compatibility but no longer do useful work:

- `phileas ingest` — Daemon-side LLM extraction was removed; ingest happens through the Claude Code Stop hook / host-driven extraction.
- `phileas consolidate`, `phileas contradictions` — Daemon-side LLM consolidation and contradiction scans were removed.
